# FieldCon

FieldCon is an offline Android planning aid for field work, built to answer two questions before a session starts: when is it safe to work, and can you see what you are doing. Thermal guidance comes from published US Army TB MED 507 tables, which turn a wet bulb globe temperature reading plus work rate, acclimatization and clothing into a heat category, a work/rest cycle and a water intake rate. Light and darkness are worked out by astronomical calculation on the device, so sunrise, sunset, twilight and moon times need no network connection. The app proposes the safest working windows for the day and lets you record an approve or deny decision alongside the conditions it was based on. This repository is currently a user interface prototype, meaning the screens, theme and copy are in place while the calculations and storage behind them are not yet implemented. FieldCon is a planning aid rather than a measuring instrument, and it depends entirely on the conditions you supply.
